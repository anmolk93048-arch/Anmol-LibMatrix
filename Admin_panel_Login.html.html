💳 Razorpay Setup — Agent Subscription ✕
Yahan sirf apni Razorpay Key ID (public, "rzp_live_..." ya "rzp_test_...") daalein — ye Agent App ke payment page par checkout kholne ke liye use hoti hai aur browser mein safe hai.

⚠️ Zaroori: Razorpay Key Secret kabhi bhi is (ya kisi bhi) HTML/browser file mein na daalein — ye publicly visible ho jaata hai aur koi bhi aapke Razorpay account se paisa nikaal sakta hai. Order create karne aur payment verify karne ke liye ek chhota sa server/serverless function (Node.js/Firebase Cloud Function) chahiye hoga jahan Key Secret surakshit rahe. Jab tak wo backend nahi banta, yahan sirf Key ID se checkout khulega, payment verification manual/records ke through hogi.
Agar aapke paas backend hai jo Razorpay order banata hai aur signature verify karta hai, uska URL yahan daalein. Khaali chhoda to Agent App sirf manual/offline renewal dikhayega.
